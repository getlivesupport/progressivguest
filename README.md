# Progressive Payment Guide

A lightweight static landing page for Progressive insurance bill payment guidance, focused on:

- one time payment
- guest payment
- pay without logging in
- Progressive payment options
- AutoPay and monthly billing comparisons
- grace period and late payment guidance
- FAQs aligned to real search intent

## Files

- `index.html` — landing page markup, CSS, JavaScript, and structured data

## Notes

- This project is a static HTML page intended for GitHub Pages or similar static hosting.
- The page includes mobile-first layout improvements, SEO-focused metadata, and FAQ content designed for human readers and search visibility.
- External payment links point to Progressive payment flows.
- Phone numbers are used sparingly and intentionally for support-related calls.

## Local preview

Open `index.html` directly in a browser, or serve the folder with a simple local static server.

Example:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Deployment

This repo is suitable for GitHub Pages deployment using a static site workflow.
